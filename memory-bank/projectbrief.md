# Project Brief

## 使命
以可复现的工程标准，复刻 Jegadeesh & Titman (1993) 美股价格动量异象，并扩展参数稳健性检验与交易成本敏感性分析。

## 核心需求
1. **方法论严谨**：Newey-West 标准误（非普通 OLS）、前视偏差用独立重算验证（非设计声明）、退市收益处理显式化
2. **诚实的负面结果**：不显著或为负的结果照实报告，不做筛选或美化
3. **分层清晰**：组合构建全部落在 SQL 层，R 层对组合级数值严格只读
4. **双语呈现**：英文为主 README，中文对照版
5. **可视化双轨**：每张图同时提供静态 PNG 与交互式 HTML

## 已交付
- 完整 SQL 管线（01-05）+ R targets 管线 + testthat 测试套件
- 交互式图表已推送至 https://github.com/ahish-avg/momentum-factor

## 关键结论
12-1 标准设定在本样本（1990-2025，267 万条个股月度观测）未能复现；唯一显著且抗成本的窗口是 6 个月建仓、跳过 1 个月。
